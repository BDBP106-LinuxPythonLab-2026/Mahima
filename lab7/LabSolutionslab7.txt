(ii)The output for chmod command was 0002. The first 0 is the sticky bit and the next three digits tell us about the default permission for files and directories.
To get the default permissions for directories you need to subtract the value(002) from maximum possible permission(777) = 775 [user(list files,create/delete/modify files,enter directory and access files);group(list files,create/delete/modify files,enter directory and access files);others(list files,enter directory and access files)]
To get the default permissions for files you need to subtract the value(002) from maximum possible permission(666) = 664 [user(read,write);group(read,write);others(read)].
